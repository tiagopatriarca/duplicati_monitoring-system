Guia de Integração com o Duplicati

Como configurar o Duplicati para enviar os relatórios de resultados de jobs para este sistema.

1. Endereço da URL do Webhook

Seu servidor esta pronto para receber notificações no seguinte endpoint HTTP POST:

http://<IP-DO-SEU-SERVIDOR>:5000/api/webhook/duplicati

2. Passos para Configuração no Duplicati GUI

  1. Abra o painel web do seu **Duplicati**.
  2. Edite o Job de Backup desejado ou acesse Configurações Globais.
  3. Navegue até a Etapa 5 (ou Opções Avançadas).
  4. Adicione a seguinte opção avançada:
    --send-http-url=http://<IP-DO-SEU-SERVIDOR>:5000/api/webhook/duplicati
  5. (Opcional) Para enviar o relatório detalhado em formato JSON, adicione também:
    --send-http-result-output-format=json
  6. Salve a configuração do Job. Pronto! Ao finalizar cada execução, o Duplicati enviará os resultados automaticamente para este sistema.

3. Testar Conexão Instantaneamente

Você pode rodar o script de simulação em Python incluído no projeto para testar o envio de notificações sem precisar aguardar um backup real:

python simulate_webhook.py
